# Implementación y Evaluación de Filtros Digitales en Python

Este repositorio contiene la implementación, simulación y análisis de filtros digitales (**Pasa Bajos**, **Pasa Altos** y **Pasa Bandas**) utilizando Python. El objetivo principal es evaluar la efectividad de los filtros procesando señales sintéticas compuestas por múltiples frecuencias y ruido blanco, analizando los resultados tanto en el dominio del tiempo como en el dominio de la frecuencia.

---

## 📋 Contenido del Repositorio

* `filtros_digitales.py`: Código fuente principal con la generación de señales, diseño de filtros IIR (Butterworth) e instrumentación gráfica.
* `README.md`: Documentación del proyecto, análisis técnico y guía de ejecución.
